# Herdr 面板 UI 设计与交互规格

版本：v2 草案（2026-10-01）。与 [PRODUCT_LOGIC.md](PRODUCT_LOGIC.md)、[SETTINGS_AUDIO.md](SETTINGS_AUDIO.md) 和 [ACCEPTANCE.md](ACCEPTANCE.md) 配套；尺寸均为像素。本文是实现目标，不是当前 `main/ui_panel.c` 的实现说明。

## 1. 设计基线

- 当前仓库硬件为 **2.16 英寸 480×480 触摸 AMOLED**，不是用户口述的 2.13 英寸 OLED。以下为 480×480 方形可视区域规格；实物屏幕若有圆角/遮挡，需用厂商模板量取安全边界后整体内缩。另一块 2.13 英寸屏幕若分辨率或输入方式不同，必须重做布局并重新验收，不能简单缩放。
- 目标是“抬眼判断、两步处理”。默认只占一屏的四宫格；详情先告诉用户当前 agent、状态、具体待处理内容，再给动作。所有危险动作都要确认，且确认页能看清影响对象。
- 同一页面最多一个主要任务。设置不在首页长期占用一个网格；无底部永久 Tab 栏。触摸区要大，少用需要精细操作的列表、虚拟键盘或长段终端文本。

| --- | --- |
| 背景 | `#080D12`；卡片 `#151E27`；分割线 `#293643`。AMOLED 使用深色降低刺眼与烧屏。 |
| 正文/次级 | `#F2F6FA` / `#AEBCC9`；禁用 `#667687`，且始终附原因。 |
| 待处理 | `#FF6B68` + `!`，不闪烁文字。 |
| 运行中 | `#F7BD4A` + 进度弧。 |
| 待查看 | `#69B5FF` + 勾形。 |
| 空闲 | `#70C995` + 空心圆。 |
| 状态未知/离线 | `#8D9BAA` + 问号/断线。 |
| 字体 | 语言分区见下方约定。中文用有中文字形的 18/20/24/28 px 字体，正文至少 18 px；终端摘录使用有 CJK fallback 的等宽 16 px。 |

### 2.1 语言约定：会话中文，设置英文

设备端文案按屏幕分区，不做整体单语选择：

| 区域 | 屏幕 | 语言 | 理由 |
| --- | --- | --- | --- |
| 会话 | `HOM` `DET` `CNF` `RST` | **中文** | 直接承载 agent 名称、会话状态、待处理文案，目标用户读中文最直接。 |
| 设置 | `SET` `QUICK` `SOUND` `DISPLAY` `SESSIONS` `CONNECTION` `ABOUT` | **英文** | 设置项是固定枚举与数值，不依赖 CJK 字形即可完整表达；避免设置页因字体子集缺字而显示 `□`。 |
| 配网 | `PRV` | 中文 | 首次开机引导，面向普通用户。 |

实现约束：

- 只有会话区与配网区依赖 `main/fonts/font_cjk_*.c`；设置区文本必须全部落在 Montserrat 已有字形内。
- `ui_font()` 的每个字号都必须挂 CJK fallback，否则该字号的中文会渲染成 `.notdef` 方框（LVGL 的 `lv_font_get_glyph_dsc` 沿 `fallback` 链回溯，缺字才落到占位符）。
- 字体子集是 GB2312 一级字库（3755 字）截断集，新增中文文案若不在子集内必须同步扩充 `tools/fonts/cjk_common.txt` 并重新生成，否则显示为空白。
- 设置页在 LVGL 堆紧张（见 §7），必须保持懒加载；新增设置页不得在 `ui_panel_init()` 中无条件构建。
| 图标 | 用 LVGL 简单矢量/内置符号，旁边有文字；不依赖彩色 emoji。 |
| 截断 | 名称最多两行；路径首页仅末段一行；越界用省略号。永远保留完整名字在详情“信息”页。 |

色盲与低亮环境均通过“文字 + 形状”读状态。选中卡片用 2 px 高亮描边，不把 Herdr 的 `focused` 当本设备的选中态。显示屏亮度默认 45%，设置中 10–100% 可调，静置 60 秒降亮到 15%，触摸后恢复；配网二维码及确认页不自动熄屏。新请求/完成既可视觉提示又可播 Herdr 对应音效；静音不隐藏文字或状态图形。[声音规则](SETTINGS_AUDIO.md)

## 3. 页面地图与固定层级

```text
启动/连接
 ├─ 配网二维码 ↔ 手机配网页
 └─ 四宫格（默认页） ── 点卡片 ─→ 会话详情 ── 操作 ─→ 全屏确认/结果
                 └─ 菜单 ─────────→ 快捷设置（静音、亮度）→ 设置列表
                                                       ├─ 声音 / 显示 / 会话
                                                       └─ 连接 / 关于 / 重新配网
全局：Wi-Fi/服务器离线条；动作结果提示；返回手势/实体 KEY 后退。
```

开机先显示 `BOOT`：深色底、居中 HERDR 标识、四个代表首页网格的方块依次点亮，底部细进度条。总时长至少 1.2 秒；若网络/配网初始化更久，进度条停在终点直到目标页就绪。动画不得阻塞网络任务和触摸任务，不播放提示音。开启“减少动画”后四格静态显示约 0.4 秒。随后进入配网二维码或首页，不短暂闪出错误目标页。

所有页面共享：左上 72×64 返回热区（首页除外）；右上 72×64 菜单热区；重要操作按钮高至少 80 px。点击反馈应在 80 ms 内出现。双击不增加功能；长按不触发允许或拒绝。

## 4. 480×480 布局

坐标原点为左上；下表是 LVGL 布局基线。适配实物时可微调，不能遮住文案和热区。

### 4.1 双列滚动会话墙 `HOM`

全触屏、无实体按键，且用户要一眼看到更多会话，所以首页是**一个可纵向滚动的双列
卡片墙**，不再分页、没有翻页手势、没有页码。

| 区域 | 坐标/尺寸 | 内容 |
| --- | --- | --- |
| 顶栏 | `16,20,448,50` | `HERDR` 24 px、连接状态 18 px、`待处理 N` 18 px、电量百分比 + 细电量条、菜单按钮 `64x48 @400,12`。 |
| 卡片墙 | `4,66,472,340` | `LV_FLEX_FLOW_ROW_WRAP`，`pad_row`/`pad_column` = 6 px，可纵向滚动，滚动条 `AUTO`。 |
| 卡片 | `229x78`，间距 6 px | 一行两张，10 行复用池 = 最多 20 个会话。 |
| 空状态 | `40,200,400,80` | `暂无活跃会话` 24 px 居中，仅 0 会话时显示。 |
| 提示行 | `16,406,448,20` | 声音提示（临时）。 |
| 底部提示 | `16,438,448,20` | `scroll` 16 px 居中，提示可滑动。 |

卡片内布局：左上 18x18 状态形状（内含状态符号），右侧名称 16 px
（`x=32,y=6,w=CARD_W-40`）、状态文字 14 px（`y=26`）；左下 8-bit agent 图标
`16x16 @9,50`，右侧 agent 类型 12 px（`y=50`）；右下项目末段 12 px 右对齐
（`y=CARD_H-20`）。整块卡片为点击热区。空槽显示暗色虚线框 + `空位`，不触发
点击。`blocked` 卡片边框 2 px `COLOR_PENDING`，其他 1 px 暗色。

```text
┌────────────────────────────────────┐
│ HERDR  ●在线  待处理 2   92%  ⚙│
│ ┌─────────────┐ ┌─────────────┐   │
│ │▣! w1:p2     │ │◌ docs       │   │
│ │  Claude     │ │  Pi         │   │
│ │ ▣ 空闲      │ │ ▣ 待处理    │   │
│ └─────────────┘ └─────────────┘   │
│ ┌─────────────┐ ┌─────────────┐   │
│ │◕ tests      │ │✓ api        │   │
│ │  OpenCode   │ │  Claude     │   │
│ └─────────────┘ └─────────────┘   │
│            scroll                │
└────────────────────────────────────┘
```

**为什么用原生滚动而不是翻页手势：** 全触屏没有实体按键，翻页手势必然和卡片点击
抢事件。LVGL 的 `lv_indev_scroll_handler` 在容器真的滚动了时会抑制底层卡片上的
`CLICKED`，所以「滑动 = 滚动、点一下 = 打开」由框架保证，不需要自己判断手势方向。

### 4.1b 待机 `STB`

空闲后进入待机，两段式（见 §4.3）。**时钟 + 呼吸光晕**而不是静止画面，
因为 AMOLED 长时间显示静止内容会烧屏。

| 区域 | 坐标/尺寸 | 内容 |
| --- | --- | --- |
| 呼吸环 x3 | 居中，直径 `300/340/380` | 2 px 描边，`COLOR_ACCENT`，无填充。缩放 80%..100% 三角波，透明度 10%..45%，三环相位各差 2 s，周期 6 s。 |
| 时钟 | `40,190,400,~50` | `HH:MM`，24 px 字体经 `transform_scale=256` 放大到约 96 px 视觉高度，水平居中。 |
| 日期 | `40,292,400,24` | `Sat Oct 3`，16 px `COLOR_DIM` 居中。时钟未同步时显示 `--:--` 与 `等待网络时间`。 |
| 提示 | `40,414,400,20` | `触摸或摇一摇唤醒` 14 px `COLOR_DISABLED` 居中。 |

时钟用**本地时间**：SNTP 保持 `time()` 为 UTC，加 `prefs.utc_offset_minutes`
后 `gmtime_r()`，与 `panel_worker.c` 的 `quiet_now()` 同一套偏移，避免两处时间
不一致。屏幕切换用 `lv_screen_load()` 而非带淡入的动画——没人盯着的时候闪一下
没有意义。

### 4.2 会话详情 `DET`

| 区域 | 坐标/尺寸 | 内容 |
| --- | --- | --- |
| 标题栏 | `8,8,448,48` | 返回热区 `56×48`、agent 名称 24 px、菜单热区 `56×48`（"刷新"）。 |
| 元数据 | `16,80,448,20` | “更新于 N 秒前” 16 px 右对齐。 |
| 动作图标 | `148/212/276,108,56×56` | 三个圆形图标，见下。 |
| 图标说明 | `16,168,448,14` | 一行 14 px 居中，说明当前图标语义（如 `停止请在主机按 Esc`）。 |
| 内容卡 | `16,192,448,232` | 待处理卡优先；无卡时显示输出摘要。可纵向滚动。 |
| 底部提示 | `16,434,448,20` | `操作前请确认` 或禁用原因，16 px 居中。 |

**为什么是图标而不是底部大按钮：** 底部 88 px 按钮区挤掉了 56 px 的内容高度，
而这块 480x480 的屏上每一行输出都是决策依据。移到上半部后内容区从 176 px 长到
232 px（多约 4 行输出）。板子上**没有任何实体按键 GPIO**（所有引脚被 LCD SPI /
I2C / 触摸 / I2S 占满，背光是 SH8601 的 DCS 寄存器），所以图标必须**可点击**，
不能只做状态指示。

**图标槽位语义**（`x = 148 + i*64`，直径 56，可用时填充为该语义色、文字转黑底
色，不可用时 `COLOR_CARD` 底 + `COLOR_DISABLED` 描边与符号）：

| 场景 | 槽 0 | 槽 1 | 槽 2 |
| --- | --- | --- | --- |
| 待审批 / 待回答 | `√` 允许一次（`COLOR_DONE`） | `×` 拒绝（`COLOR_PENDING`） | `⚙` 始终允许（`COLOR_WORKING`） |
| idle/done 无待决 | `▶` 继续（`COLOR_ACCENT`） | `×` 停止（**永远灰暗**） | `↻` 自动（`COLOR_WORKING`） |

只有网关 `choices` 位掩码里**确实存在**的选项才点亮，固件绝不发出网关会拒绝的
请求。`stop` 目前不在网关的 `Action` 字面量里
（`refer/herdr-restful/backend/app/panel/view_models.py`），
所以停止图标常灰并在说明行提示"停止请在主机按 Esc"；等网关支持后，
只要加一个 `PANEL_CHOICE_STOP` 位和 `panel_api_client.c` 的解析分支即可点亮。

点击图标后仍走完整的 `CNF` 确认页（§4.3），图标只是入口。
不可用时用 `LV_STATE_DISABLED`，`on_action_btn()` 里再挡一层
（`PANEL_ACT_NONE` / `PANEL_ACT_STOP` 直接返回），双保险。

输出摘要绝不作为可点击“审批选项”直接高亮。用户看到的是网关整理的
`pending.summary` 与 `impact`；完整内容不足以在屏幕上呈现时不出现可执行图标。
长路径可拆为项目名/相对路径两行，不用水平跑马灯隐藏决定性文本。

### 4.3 决策确认 `CNF`

整个屏幕切换为独立确认页，不用小型弹窗盖住详情，以便看清对象：

```text
返回                 确认允许一次

Claude · project-api
请求执行：npm test
工作目录：/repo/project-api
范围：仅本次命令

当前提示刚刚更新 2 秒前

[ 取消，返回详情 ]
[ 确认允许一次   → ]
```

标题 26 px；核心命令/路径/范围 20 px，最多 5 行且允许竖向滚动。取消按钮在上、确认在下，均至少 80 px 高且相隔 12 px；“始终允许”确认页要显示未来影响范围并要求按住确认 1.2 秒。拒绝仍确认一次，防误触。“继续”确认页展示将发出的**完整提示词**。10 秒内未确认自动返回详情；待处理卡更新则立即取消确认，不保留旧按钮。

### 4.4 结果 `RST`

- 发送中：按钮变不可点击，轻量旋转线条和“正在发送…”；超过 5 秒显示“等待主机回报”。禁止二次提交。
- 成功送达：显示 `已发送，等待 Agent 响应`，回读后才显示 `已处理`。若回读未能确认，显示 `结果待确认`，附“查看主机”或“刷新”。
- 失败：`现场已变化`、`网络中断，结果未知`、`不支持该操作` 分别有清晰文案。结果未知页面没有“重试”快捷键；用户先返回详情重新获取现场。

### 4.5 配网二维码 `PRV`

`标题 y=24`：`连接设备热点`。白底黑码区域 `x=112,y=92,w=256,h=256`，其中二维码本体不超过 232×232，四周留 ≥ 12 px 纯白静区。下方 `SSID: HerdrPanel-XXXX`、临时热点密码、`扫码加入 Wi-Fi`、`没有弹出网页？192.168.4.1`。二维码内容必须是标准 Wi-Fi payload，仅含设备热点凭据；禁止把家用 Wi-Fi 密码或后端令牌编码进去。二维码页面不播放背景动画，防止扫码失败。首次配置成功后显示 `配置已保存 · 正在连接`；连接失败可重试或再次打开配网页。

### 4.6 快捷设置与设置 `SET`

**快捷面板**：从首页顶栏菜单进入，占满 480×480；顶部 64 px 为返回/标题，`y=72..160` 两个并排 216×80 大按钮分别为 `静音/开声` 与 `声音设置`；`y=172..280` 是 448×80 亮度滑杆（10–100%，两端有减/加 56×80 热区）；`y=300..380` 是 `全部设置` 大按钮；底栏显示当前连接和“保存中/已保存/保存失败”。静音一按立即停播并显示带斜杠的扬声器图标；亮度拖动即时预览，松手后保存。离线时这两个本机设置仍能改。不能通过长按首页卡片暗中静音。

**设置列表**：独立页面顶部 `0..64` 返回与“设置”；`y=72..420` 为可纵向滚动的 6 个大行，每行高 ≥ 72 px，顺序为 `声音`、`显示`、`会话`、`连接`、`关于`、`重新配网`。前 5 行显示当前值的简短摘要，如“声音 · 开 · 50%”或“会话 · 3 秒刷新”；最后一行用危险操作颜色且二次确认。底部固定 `y=424..480` 返回首页按钮。滚动时不把行按钮误触，按下移动 > 12 px 取消点击。每个子页都有 72×64 返回热区，不在同一屏塞 15 个开关。

**声音子页**分两层：第一页仅 `总开关`、`音量`、`请求音`、`完成音`、`试听`，用 76–88 px 行高；第二层 `更多声音设置` 进入 `通知范围`、`Agent 音效`、`免打扰`。试听页两个 ≥ 96×80 的 `试听请求音` / `试听完成音` 按钮，旁边写“只播放本机声音，不会操作会话”。总开关关时，其他开关仍可配置但清楚显示“当前静音”；试听必须明确标注可临时发声。音量滑杆始终显示数值，0% 展示“静音”，无需靠听觉猜值。Agent 类型列表只显示网关支持/目前见过的类型及 `继承/开/关` 三态选择，不出现未知自由输入。

**显示子页**：亮度、`Standby Clock`、`Blank Screen`、`Wake on Motion`、
`Dimmed Level`、`Reduce Motion`。待机两段时长的语义与唤醒方式见 §4.7。
调整减少动画时当前页马上停止持续动效；关闭视觉提醒只去掉额外脉冲，不能隐藏
待处理状态。**会话子页**：刷新间隔 2/3/5/10 秒、卡片排序、隐藏空闲、视觉提醒、
继续提示词当前摘要和 `扫码编辑`。选择排序后回首页保持所选会话可见；改变轮询
间隔显示“下次刷新开始生效”。

**连接子页**：Wi-Fi SSID（仅名称）、网关地址、Herdr 健康、最近更新时间、`立即刷新`、`扫码编辑连接`。扫码编辑时展示临时 WPA2 热点 QR 及 5 分钟倒计时，手机网页改 URL、Wi-Fi 和继续提示词；保存后返回连接页并明确显示重连状态。**关于**：固件/网关协议版本、设备 ID 后四位、硬件/声音状态、帮助 QR。**重新配网**：列出会清除的凭据，不清除声音/显示/会话偏好；二次确认后进入配网 QR。

连接子页同时显示电池百分比、充电/外部供电状态。电量由板载 AXP2101 后台读取，每 15 秒更新；无读数时不从电压推算百分比。低于或等于 15% 时百分比和电量条变红，充电中明确标“充”。供电信息不得进入审批上下文或影响动作安全判定。

免打扰时间用两个 24 小时制步进控件，每次 ±15 分钟；同页显示 UTC 偏移（默认 +08:00，可调），并注明固定偏移不自动处理夏令时。时钟未同步时展示“时间未同步，声音暂时关闭”。页面有保存状态及回滚提示，不能把预览当保存成功。Wi-Fi 密码、服务端令牌和复杂 URL 仅在临时手机网页编辑；480×480 屏幕上不做虚拟键盘表单。首页菜单不能有“重置”、“Auto 模式”一按即执行的项目。详情菜单可含“会话信息”、“刷新”、“Auto 模式说明”，以及条件满足时的“始终允许”。全部字段的默认值、范围和生效时机见 [SETTINGS_AUDIO.md](SETTINGS_AUDIO.md)。

### 4.7 待机与唤醒

待机是**两段式**，中间加全黑是因为 AMOLED 长时间发光既费电又烧屏，而"一直
显示时钟"的中间态在夜里其实也很亮。两段阈值都可在设置里改，也可单独关掉。

| 状态 | 条件 | 行为 |
| --- | --- | --- |
| 正常 | 空闲 < `Standby Clock` | 全亮度，双列会话墙静止 |
| 待机 `STB` | 空闲 ≥ `Standby Clock`（默认 3 min） | `SCR_STANDBY`：大号时钟 + 三环呼吸，亮度降到 `Dimmed Level`（默认 15%） |
| 全黑 | 待机中且空闲 ≥ `Blank Screen`（默认 5 min） | 亮度 0。控件不销毁，所以唤醒是瞬时的、无需重建 |
| 唤醒 | 触摸 **或** 摇一摇 | 立刻回正常态，全亮度 |

**触摸唤醒不需要写代码。** LVGL 的 `lv_indev.c` 在任何 indev 活动时都会重写
`disp->last_activity_time`，而 `lv_display_get_inactive_time()` 读的正是这个字段，
所以一次点击就让空闲时间归零，`update_standby()` 自然退出待机。

**加速度唤醒需要自己轮询。** 板载 QMI8658 与 PMIC / 触摸 / codec 共用 I2C0，
`main/panel_motion.c` 以 10 Hz 采样加速度矢量模长 `|a|`：

- 判据是 `| |a| - 9.807 | > 3.0 m/s²` **连续 2 次采样**。
  门限本身排除桌面振动和缓慢漂移；连续两次排除 I2C 噪声的单点尖峰
  （200 ms 内完成判定）。
- 空闲超过 30 s 后采样率降到 2 Hz——没人看的面板不该整夜以 10 Hz 挂在总线上。
- 唤醒标志是 sticky 的，由 LVGL tick 消费（`panel_motion_wake_pending()`），
  避免两个任务争抢。
- IMU 缺失不是错误：先试 `0x6B` 再试 `0x6A`，都失败就只记一条 warning，
  触摸仍然唤醒；设置页显示 `No IMU` 而不是假装能开。

`Reduce Motion` 开启时不做呼吸环缩放（只保留静态环 + 时钟），避免晕动症用户
看到持续缩放。`CNF` 与 `PRV` 页**永不进待机**：确认页正在展示需要阅读的文本，
配网二维码必须等手机扫完。

## 5. 动效规范

动效必须帮助理解状态变化，不遮盖文字或干扰扫码：

| 事件 | 动效 | 时长/约束 |
| --- | --- | --- |
| 页切换 | 旧页水平移出，新页移入；详情从右进入，返回反向 | 180–220 ms，ease-out；低性能时可直接切换。 |
| 按下 | 按钮/卡片亮度提升 8% + 边框加亮 | 80 ms 内响应，松开 120 ms 恢复。 |
| `working` | 状态图形的 270° 弧缓慢旋转 | 1.4 s/圈，只刷新图标小区域；最多 4 个同时动。 |
| 新 `blocked` | 卡片描边从 60% 到 100% 亮度 2 次 | 单次 1.2 s，总共 2 次；之后静态红边。不得无限闪烁。 |
| `done` | 勾形 150 ms 淡入 | 仅状态改变时一次。 |
| 新 `request` 声音事件 | 对应卡片短亮 2 次，首页待处理计数即时更新；若声音允许则播 Herdr `request` 素材 | 视觉 1.2 s；音频不与 LVGL 动画同线程；免打扰只压声音。 |
| 新 `done` 声音事件 | 对应卡片勾形淡入；若声音允许则播 Herdr `done` 素材 | 150 ms；不从第一次同步的 `done` 快照触发。 |
| 静音/音量/保存 | 图标和数值即时变化；保存结果以一行短文案呈现 | 静音 100 ms 内停播；失败回滚到已保存值。 |
| 发送中 | 动作按钮内短旋转线条 | 至多 5 s，之后静态等待文案。 |
| 错误/旧数据 | 顶栏图标和说明滑入 | 180 ms，不全屏闪烁。 |
| 进入待机 | 直接切屏（无淡入） | 没人盯着时闪一下没有意义。 |
| 待机呼吸环 | 缩放 80%..100% + 透明度 10%..45% 三角波，三环相位差 2 s | 周期 6 s，`LV_ANIM_OFF` 逐帧写入；`Reduce Motion` 时关闭。 |
| 待机时钟 | 每分钟翻转一次文本 | 无过渡动画：分钟跳变本身就是动效，任何补间都会看起来卡。 |

配置中的“减少动画”关闭持续旋转与轮廓脉冲，但保留触摸反馈和明确的状态文字；“视觉提醒”只控制额外脉冲。设备静置降亮时暂停持续动画；任何动画不得触发网络请求或重建整个 LVGL 屏幕。屏幕唤醒后先显示快照年龄，再刷新数据。音效由事件驱动，动画不能间接触发声音。

## 6. 小屏文案与异常状态

| 场景 | 屏幕文案 | 操作 |
| --- | --- | --- |
| 未配网 | `扫码配置 Wi-Fi` | 扫码/手动进网页。 |
| Wi-Fi 连接中 | `正在连接 Wi-Fi` | 等待；长时间失败显示“重新配网”。 |
| REST 服务不可达 | `服务器未连接` + 最后更新时间 | `刷新连接`、`查看地址`。 |
| Herdr socket 异常 | `Herdr 服务异常` | `查看主机`、`刷新连接`。 |
| 列表为空 | `暂无运行中的 Agent` | `刷新`，不显示四张假卡。 |
| 状态 `unknown` | `状态未知` | 只读，提示主机检查。 |
| `blocked` 无可解析选项 | `需要在主机处理` | 三动作禁用。 |
| 现场变更 | `提示已变化，请重新查看` | 返回详情刷新。 |
| 输入已发但未确认 | `结果待确认` | 查看新详情/主机，不重试。 |
| 超过 24 个 | `仅显示前 24 个 / 共 N 个` | 手机/主机处理其余会话。 |
| 声音关闭 | `已静音` + 带斜杠扬声器图形 | 快捷面板一按开声；不补播旧事件。 |
| 声音硬件故障 | `声音不可用 · 查看硬件` | 状态/动作仍可用；声音子页说明。 |
| 免打扰时间未同步 | `时间未同步 · 暂停声音` | 手动检查网络/时间，视觉提醒照常。 |
| 设置保存失败 | `保存失败 · 已恢复原值` | 可再次设置；不误报已保存。 |

多语言：会话与配网区固定中文，设置区固定英文（分区约定见 §2.1）；agent 名称、路径与输出按原始 UTF-8 显示。字体缺字用 `□` 占位且不能造成排版崩溃。所有服务端文字必须做终端控制字符过滤，不能作为 UI 指令。

## 7. LVGL 实现边界

- 建议把首页卡片、详情待处理卡、确认页做成独立组件，接收只读 `panel_view_model`。状态、连接、待处理三类数据分层，不直接从回调读全局网络缓冲。
- 固定位置重复更新 label 文本和样式；避免每 200 ms 重建对象。刷新周期与动画定时器分开。网格仅当 `terminal_id`/可见字段变化才局部刷新。
- 二维码优先以 LVGL QR 组件渲染到 232×232 内；码周围保持白色静区。触摸坐标需经实机校准，翻页手势不得触发卡片点击。
- 当前 `main/ui_panel.c` 已有可操作的声音/显示/会话子页、运行时偏好、开机动画、电量显示和临时手机编辑入口。仍须在真机检查触摸、字体、扫码与供电读数；连接编辑采用软重启进入/退出热点，保存后返回首页，下一轮可优化为仅重连并返回连接页。按 [ACCEPTANCE.md](ACCEPTANCE.md) 逐项验收。

## 8. 设计验收

在真机以正常握持距离验证：四格状态与项目名可读；任意可点区域准确命中；QR 在两种常见手机上可扫描；长名称/中文/多行路径不重叠；离线时动作不可用；任何确认页均能看清对象和范围；动画不会造成可察觉卡顿。静音、音量、免打扰及两类试听需在实际扬声器上验证，屏幕截图不能证明音频行为。桌面 480×480 截图只能检查排版，不能替代真机可读性和触摸测试。
