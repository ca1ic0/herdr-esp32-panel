# Herdr 面板 UI 设计与交互规格

版本：v1 草案（2026-09-30）。与 [PRODUCT_LOGIC.md](PRODUCT_LOGIC.md) 和 [ACCEPTANCE.md](ACCEPTANCE.md) 配套；尺寸均为像素。本文是实现目标，不是当前 `main/ui_panel.c` 的实现说明。

## 1. 设计基线

- 当前仓库硬件为 **2.16 英寸 480×480 触摸 AMOLED**，不是用户口述的 2.13 英寸 OLED。以下为 480×480 方形可视区域规格；实物屏幕若有圆角/遮挡，需用厂商模板量取安全边界后整体内缩。另一块 2.13 英寸屏幕若分辨率或输入方式不同，必须重做布局并重新验收，不能简单缩放。
- 目标是“抬眼判断、两步处理”。默认只占一屏的四宫格；详情先告诉用户当前 agent、状态、具体待处理内容，再给动作。所有危险动作都要确认，且确认页能看清影响对象。
- 同一页面最多一个主要任务。设置不在首页长期占用一个网格；无底部永久 Tab 栏。触摸区要大，少用需要精细操作的列表、虚拟键盘或长段终端文本。

## 2. 视觉系统

| 项目 | 规范 |
| --- | --- |
| 背景 | `#080D12`；卡片 `#151E27`；分割线 `#293643`。AMOLED 使用深色降低刺眼与烧屏。 |
| 正文/次级 | `#F2F6FA` / `#AEBCC9`；禁用 `#667687`，且始终附原因。 |
| 待处理 | `#FF6B68` + `!`，不闪烁文字。 |
| 运行中 | `#F7BD4A` + 进度弧。 |
| 待查看 | `#69B5FF` + 勾形。 |
| 空闲 | `#70C995` + 空心圆。 |
| 状态未知/离线 | `#8D9BAA` + 问号/断线。 |
| 字体 | 中文用有中文字形的 18/20/24/28 px 字体，正文至少 18 px；终端摘录使用有 CJK fallback 的等宽 16 px。当前 Montserrat 不含中文，必须新增字体资产或把设备端文案统一改成可读英文。 |
| 图标 | 用 LVGL 简单矢量/内置符号，旁边有文字；不依赖彩色 emoji。 |
| 截断 | 名称最多两行；路径首页仅末段一行；越界用省略号。永远保留完整名字在详情“信息”页。 |

色盲与低亮环境均通过“文字 + 形状”读状态。选中卡片用 2 px 高亮描边，不把 Herdr 的 `focused` 当本设备的选中态。显示屏亮度默认 45%，设置中 10–100% 可调，静置 60 秒降亮到 15%，触摸后恢复；配网二维码及确认页不自动熄屏。

## 3. 页面地图与固定层级

```text
启动/连接
 ├─ 配网二维码 ↔ 手机配网页
 └─ 四宫格（默认页） ── 点卡片 ─→ 会话详情 ── 操作 ─→ 全屏确认/结果
                 └─ 菜单 ─────────→ 设置（连接、显示、关于、重新配网）
全局：Wi-Fi/服务器离线条；动作结果提示；返回手势/实体 KEY 后退。
```

所有页面共享：左上 72×64 返回热区（首页除外）；右上 72×64 菜单热区；重要操作按钮高至少 80 px。点击反馈应在 80 ms 内出现。双击不增加功能；长按不触发允许或拒绝。

## 4. 480×480 布局

坐标原点为左上；下表是 LVGL 布局基线。适配实物时可微调，不能遮住文案和热区。

### 4.1 四宫格首页 `HOM`

| 区域 | 坐标/尺寸 | 内容 |
| --- | --- | --- |
| 顶栏 | `x=16,y=8,w=448,h=60` | 左侧 `HERDR` + 连接图标；中间 `待处理 N`；右侧 72×56 菜单热区。 |
| 左上卡 | `16,76,218,160` | 第 1 个 agent。 |
| 右上卡 | `246,76,218,160` | 第 2 个 agent。 |
| 左下卡 | `16,248,218,160` | 第 3 个 agent。 |
| 右下卡 | `246,248,218,160` | 第 4 个 agent。 |
| 底栏 | `16,420,448,52` | `第 1/3 页`、`共 10 个`、左右轻量箭头；离线时底栏改为“离线 · 最后更新 20:14”。 |

卡片内布局：左上 24 px 状态形状，右侧 agent 名称 20 px 最多 2 行；中部状态文字 24 px；下部项目末段 18 px；右下可选 16 px `w1:p2`。卡片的**整块区域**为点击热区。空槽显示虚线框 + `空`，不触发点击；0 会话时改成居中空状态，不画四张空卡。`blocked` 卡片边框 2 px 红色，其他卡 1 px 暗色。

```text
┌────────────────────────────────────┐
│ HERDR    待处理 2            菜单  │
│ ┌──────────────┐ ┌──────────────┐ │
│ │ ! Claude     │ │ ◌ Pi         │ │
│ │ 待处理       │ │ 空闲         │ │
│ │ project-api  │ │ docs         │ │
│ └──────────────┘ └──────────────┘ │
│ ┌──────────────┐ ┌──────────────┐ │
│ │ ◕ OpenCode   │ │ ✓ Claude     │ │
│ │ 运行中       │ │ 待查看       │ │
│ │ web          │ │ tests        │ │
│ └──────────────┘ └──────────────┘ │
│                 第 1/2 页   ›      │
└────────────────────────────────────┘
```

首页手势：左右滑动距离 ≥ 48 px 且水平距离 > 垂直距离的 1.5 倍翻页；卡片按下后移动 > 12 px 则取消点击。最左/右页轻微回弹 120 ms，无循环翻页。点“待处理 N”跳到第一个 `blocked` 所在页，并短暂高亮该卡；若当前详情正在确认则不受全局跳转打断。

### 4.2 会话详情 `DET`

| 区域 | 坐标/尺寸 | 内容 |
| --- | --- | --- |
| 标题栏 | `0,0,480,64` | 返回热区、agent 名称 24 px、菜单热区。 |
| 元数据 | `16,68,448,64` | 状态文字 + 图形；项目名；“更新于 N 秒前”。 |
| 内容卡 | `16,140,448,176` | 待处理卡优先；无卡时显示最多 7 行输出摘要。内容卡内允许纵向滚动，底部有 `查看完整信息请用主机`。 |
| 动作区 | `16,332,448,88` | 按当前 `choices` 显示 1–2 个主按钮：单按钮宽 448 px，双按钮各 220×88、间隔 8 px；没有动作时显示“在主机处理”。 |
| 底部提示 | `16,428,448,44` | `按操作后需确认` 或禁用原因，避免小字状态在底栏叠加。 |

**动作区显隐：**若是已识别审批卡，仅显示网关给出的“允许一次”和/或“拒绝”；若是 idle/done 且有继续提示词，仅显示“继续”；若是无法识别的 `blocked`，不显示可执行按钮，改为“需要在主机处理”。“始终允许”不占动作区，只在详情右上菜单里出现，且仅当网关明确提供该选项。连接失效或卡片过期时动作区显示禁用原因，不保留看似可点的旧按钮。

输出摘要绝不作为可点击“审批选项”直接高亮。用户看到的是网关整理的 `pending.summary` 与 `impact`，并可点“更多”看完整内容；完整内容不足以在屏幕上呈现时不出现可执行按钮。长路径可拆为项目名/相对路径两行，不用水平跑马灯隐藏决定性文本。

### 4.3 决策确认 `CNF`

整个屏幕切换为独立确认页，不用小型弹窗盖住详情，以便看清对象：

```text
返回                 确认允许一次

Claude · project-api
请求执行：npm test
工作目录：/repo/project-api
范围：仅本次命令

当前提示刚刚更新 2 秒前

[ 取消，返回详情 ]
[ 确认允许一次   → ]
```

标题 26 px；核心命令/路径/范围 20 px，最多 5 行且允许竖向滚动。取消按钮在上、确认在下，均至少 80 px 高且相隔 12 px；“始终允许”确认页要显示未来影响范围并要求按住确认 1.2 秒。拒绝仍确认一次，防误触。“继续”确认页展示将发出的**完整提示词**。10 秒内未确认自动返回详情；待处理卡更新则立即取消确认，不保留旧按钮。

### 4.4 结果 `RST`

- 发送中：按钮变不可点击，轻量旋转线条和“正在发送…”；超过 5 秒显示“等待主机回报”。禁止二次提交。
- 成功送达：显示 `已发送，等待 Agent 响应`，回读后才显示 `已处理`。若回读未能确认，显示 `结果待确认`，附“查看主机”或“刷新”。
- 失败：`现场已变化`、`网络中断，结果未知`、`不支持该操作` 分别有清晰文案。结果未知页面没有“重试”快捷键；用户先返回详情重新获取现场。

### 4.5 配网二维码 `PRV`

`标题 y=24`：`连接设备热点`。白底黑码区域 `x=112,y=92,w=256,h=256`，其中二维码本体不超过 232×232，四周留 ≥ 12 px 纯白静区。下方 `SSID: HerdrPanel-XXXX`、临时热点密码、`扫码加入 Wi-Fi`、`没有弹出网页？192.168.4.1`。二维码内容必须是标准 Wi-Fi payload，仅含设备热点凭据；禁止把家用 Wi-Fi 密码或后端令牌编码进去。二维码页面不播放背景动画，防止扫码失败。首次配置成功后显示 `配置已保存 · 正在连接`；连接失败可重试或再次打开配网页。

### 4.6 设置 `SET`

首页菜单只列 4 个项目，每行高 ≥ 84 px：

1. **连接**：Wi-Fi SSID（仅名称）、服务器地址、Herdr 健康、最近更新时间；`刷新连接`。
2. **显示**：亮度、静置降亮开关、减少动画开关。
3. **关于**：固件版本、设备 ID 后四位、Herdr/网关版本、协议版本、帮助二维码。
4. **重新配网**：说明将清除哪些凭据，二次确认后进入 `PRV`。

Wi-Fi 密码、服务端令牌和复杂 URL 仅在手机网页编辑；480×480 屏幕上不做虚拟键盘表单。首页菜单不能有“重置”、“Auto 模式”一按即执行的项目。详情菜单可含“会话信息”、“刷新”、“Auto 模式说明”，以及条件满足时的“始终允许”。

## 5. 动效规范

动效必须帮助理解状态变化，不遮盖文字或干扰扫码：

| 事件 | 动效 | 时长/约束 |
| --- | --- | --- |
| 页切换 | 旧页水平移出，新页移入；详情从右进入，返回反向 | 180–220 ms，ease-out；低性能时可直接切换。 |
| 按下 | 按钮/卡片亮度提升 8% + 边框加亮 | 80 ms 内响应，松开 120 ms 恢复。 |
| `working` | 状态图形的 270° 弧缓慢旋转 | 1.4 s/圈，只刷新图标小区域；最多 4 个同时动。 |
| 新 `blocked` | 卡片描边从 60% 到 100% 亮度 2 次 | 单次 1.2 s，总共 2 次；之后静态红边。不得无限闪烁。 |
| `done` | 勾形 150 ms 淡入 | 仅状态改变时一次。 |
| 发送中 | 动作按钮内短旋转线条 | 至多 5 s，之后静态等待文案。 |
| 错误/旧数据 | 顶栏图标和说明滑入 | 180 ms，不全屏闪烁。 |

配置中的“减少动画”关闭持续旋转与轮廓脉冲，但保留触摸反馈。设备静置降亮时暂停持续动画；任何动画不得触发网络请求或重建整个 LVGL 屏幕。屏幕唤醒后先显示快照年龄，再刷新数据。

## 6. 小屏文案与异常状态

| 场景 | 屏幕文案 | 操作 |
| --- | --- | --- |
| 未配网 | `扫码配置 Wi-Fi` | 扫码/手动进网页。 |
| Wi-Fi 连接中 | `正在连接 Wi-Fi` | 等待；长时间失败显示“重新配网”。 |
| REST 服务不可达 | `服务器未连接` + 最后更新时间 | `刷新连接`、`查看地址`。 |
| Herdr socket 异常 | `Herdr 服务异常` | `查看主机`、`刷新连接`。 |
| 列表为空 | `暂无运行中的 Agent` | `刷新`，不显示四张假卡。 |
| 状态 `unknown` | `状态未知` | 只读，提示主机检查。 |
| `blocked` 无可解析选项 | `需要在主机处理` | 三动作禁用。 |
| 现场变更 | `提示已变化，请重新查看` | 返回详情刷新。 |
| 输入已发但未确认 | `结果待确认` | 查看新详情/主机，不重试。 |
| 超过 24 个 | `仅显示前 24 个 / 共 N 个` | 手机/主机处理其余会话。 |

多语言：v1 固定中文界面；agent 名称、路径与输出按原始 UTF-8 显示。字体缺字用 `□` 占位且不能造成排版崩溃。所有服务端文字必须做终端控制字符过滤，不能作为 UI 指令。

## 7. LVGL 实现边界

- 建议把首页卡片、详情待处理卡、确认页做成独立组件，接收只读 `panel_view_model`。状态、连接、待处理三类数据分层，不直接从回调读全局网络缓冲。
- 固定位置重复更新 label 文本和样式；避免每 200 ms 重建对象。刷新周期与动画定时器分开。网格仅当 `terminal_id`/可见字段变化才局部刷新。
- 二维码优先以 LVGL QR 组件渲染到 232×232 内；码周围保持白色静区。触摸坐标需经实机校准，翻页手势不得触发卡片点击。
- 当前 `main/ui_panel.c` 的全屏虚拟键盘、固定 `allow/deny/continue` 三键和仅有 Montserrat 字体的 UI 层都与本规格不符。实现新界面时按 [ACCEPTANCE.md](ACCEPTANCE.md) 逐项替换和验证。

## 8. 设计验收

在真机以正常握持距离验证：四格状态与项目名可读；任意可点区域准确命中；QR 在两种常见手机上可扫描；长名称/中文/多行路径不重叠；离线时动作不可用；任何确认页均能看清对象和范围；动画不会造成可察觉卡顿。桌面 480×480 截图只能检查排版，不能替代真机可读性和触摸测试。
